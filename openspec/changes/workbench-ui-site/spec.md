# 工作台 UI 视觉重设计（站点版）

## 任务目标执行清单

**本轮目标**：把既有 `docs/ui-demo` 单页原型重做为一个可发布的 Qoder Site，并重构视觉系统——从「通用后台感」改为「对账工作台」表达，让核心业务机制（背对背隔离、双源对账、差异→决策）在界面上直接可见。

**预期交付**：`site/web/` 静态站点（9 页、亮暗主题、零网络请求），本地浏览器验证通过，Qoder Site 发布。

| # | 阶段 | 任务 | 完成条件 |
| --- | --- | --- | --- |
| 1 | 数据层 | 重写合成演示数据 | 不含真实业务数据的规模数字、目录路径；界面不出现本机文件路径 |
| 2 | 视觉层 | 重建设计系统 | 纸感画布 + 双标记色（人工/算法）+ 四类款式语义色；核心指标大数先行；`--site-*` 变量供 Nudge 消费 |
| 3 | 页面 | 重做九页 | 评审台三栏（候选/对账/决策）、差异谱单行化、货渠热力图带图例与转置、其余页保持一致密度 |
| 4 | 验证 | 浏览器逐页核对 | 九页无 JS 错误、无横向溢出（420px）、亮暗主题层级一致、抽屉开合正常 |
| 5 | 交付 | 变更记录与发布 | openspec 记录、工作分支提交、Qoder Site 发布 |

## 完整可观察结果

打开站点首页，看到的是「三方对账：商品部人工画像 vs 算法预测画像」的评审工作台：左侧候选目录、中栏①背对背（两卡之间有一道可见的「互不可见」隔离缝）与②面对面（差异谱 + 逐维差异行，人工值朱砂、算法值靛蓝，差异强度条连接两者）、右栏③决策（建议动作大字 + 四类动作单选）。九个页面均可通过左侧导航切换，亮暗主题可切换并记忆，热力图单元格可点开抽屉查看正负向证据。

## 验收标识

- **R1 合成数据**：`site/web/assets/demo-data.js` 中不含任何真实业务规模数字（渠道数、款数、样本量）与本机目录路径；数据源缺失原因只描述缺失类型
- **R2 视觉论点可见**：背对背两侧使用固定双色标记（人工 `--human` 朱砂 / 算法 `--algo` 靛蓝），并在两侧之间有文字标识的隔离缝；面对面用单行差异行 + 差异谱呈现
- **R3 核心指标**：每页首屏有台账条，数值与单位分离（单位降级为小字）
- **R4 九页可用**：`review / match / predict / channel-profile / product-profile / tag-search / datasource / retention / flywheel` 均渲染且无 JS 错误
- **R5 响应式**：420px 视口下九页均无横向溢出
- **R6 设计变量**：`--site-bg/fg/accent/on-accent/surface/muted/border/font/radius/space/type/motion` 全部被业务样式消费
- **R7 零出网**：页面无任何外部请求（无 CDN、无字体、无统计）

## 范围与不做事项

**做**：`site/web/` 下的静态站点、视觉系统、九页布局与交互；`docs/ui-design.md` 指针更新；README 指向更新。

**不做**：
- 不改 `packages/**` 任何代码，不动 MCP 契约
- 不接入真实数据（站点始终是合成演示）
- 不做正式前端工程化（无构建链、无组件库），保持可直接打开的静态文件
- 不删除 `docs/ui-demo/`（保留为历史原型对照；是否下线由用户决定）
- 不实现按钮背后的真实业务动作（导出、固化决策等仍为原型态）

## 允许修改路径

- `site/web/**`（新建）

- `README.md`（更新目录说明）
- `openspec/changes/workbench-ui-site/**`（本记录）

## 关键边界

- **数据边界**：站点只含合成数据；发布到云端不构成业务数据出网（合成值不来自任何真实导出）
- **背对背约束**：新品预测页人工侧字段必须可见地「封存」（斜纹底 + disabled），并有折叠说明
- **匹配内核唯一**：评审台仍不显示任何匹配分；货渠匹配页展示的是工具1 自有评分，与评审台的差异口径分开表述
- **依赖边界**：不新增任何第三方依赖；字体走系统栈

## 适用检查计划

- `node --check` 校验两个 JS 文件语法
- 本地 `python3 -m http.server` + Playwright：九页渲染、控制台错误、420px 溢出、抽屉开合、主题切换、转置与标签联动
- 人工核对：暗色主题截图、差异谱可读性、台账条层级
- 发布后：Qoder Site `published: true` 验证
